# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub
Security Advisories page. Do not open a public issue and do not include API
keys, bearer credentials, capability URLs, raw response bodies, or other
secrets in reports, logs, fixtures, or attestations.

Maintainers will acknowledge a complete report, assess affected contract
versions, and coordinate remediation and disclosure through the advisory.
Only the latest `main` revision is supported during this bootstrap phase.
